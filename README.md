# 1C_Art_ClimateAction_EcologicalEmotion
Year 1 Research Project 

This github repository contains the Quantitative Analysis I conducted on secondary data collected by Stanley and Hoggs et al. 

https://osf.io/bdwqs/overview

The data is public, and for thoroughness purposes I ensured that there were no re-publication stipulations made by the authors. 

Stanley, S., Hogg, T., Leviston, Z., & Walker, I. (2023, October 2). From anger to action: Differential impacts of eco-anxiety, eco-depression, and eco-anger on climate action and wellbeing. Retrieved from osf.io/bdwqs

All the python coding for the simple and multiple linear regression analysis was completed by Imogen Pirie. For my 1C research project, titled: How do ecological emotions influence climate action behaviour in young people?
